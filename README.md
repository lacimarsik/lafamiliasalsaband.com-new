# lafamiliasalsaband.com

New public website for La Familia Salsa Band — Prague-based Cuban Salsa, Bachata & Cha-cha-cha orchestra.

Built with [Astro](https://astro.build). Static output, no CMS.

## Develop

```sh
npm install
npm run dev
```

## Build

```sh
npm run build   # outputs to dist/
```
